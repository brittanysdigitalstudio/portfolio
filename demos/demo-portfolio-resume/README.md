Portfolio-Heavy Resume Website Template



\## Overview:

This is a portfolio-heavy resume website template built with HTML and CSS only.

It is designed to be calm, professional, accessible, and easy to customize — even

for beginners.



This template prioritizes clarity, accessibility, and ease of editing over visual complexity.



\## Who This Template Is For:

This template is ideal for:

\- Designers, developers, and creatives

\- Job seekers who want a clean portfolio + resume site

\- Anyone who prefers simple, editable code without JavaScript



No frameworks or build tools are required.



\## What's Included:

\- index.html (Homepage)

\- about.html (About page)

\- projects.html (Optional expanded projects page)

\- styles.css

\- Organized folders for images and CSS



\## How to Use:

1\. Open the files in a code editor (VS Code recommended).

2\. Edit text directly in the HTML files.

3\. Replace placeholder images in the assets/images folder.

4\. Customize colors and fonts using CSS variables in styles.css.



You do not need JavaScript to use or customize this template.



\## Customization Guide:

Safe to edit:

\- Text content inside HTML tags

\- CSS variables in :root (colors, fonts, spacing)

\- Images inside the assets/images folder



Avoid editing unless comfortable with CSS:

\- Class names

\- Grid or layout structure unless you are comfortable with CSS





\## Homepage Layout Rationale

Homepage Section Order



You may notice that the homepage highlights featured projects before the About section. This layout choice is intentional.



For portfolio-heavy resume websites, showcasing work early helps visitors (such as recruiters or potential clients) quickly understand skills and capabilities before reading longer background information.



This reflects how many people naturally scan portfolio sites:
work first, context second.



A short About preview is still included on the homepage, with a dedicated About page available for more detailed personal introduction.



If you prefer to feature the About section first, sections can be reordered easily - the template is designed to remain flexible and accessible.



\## Accessibility Notes:

Accessibility was considered during the design of this template.



Features include:

\- Semantic HTML structure (header, nav, main, section, footer)

\- Logical heading order

\- Visible keyboard focus styles

\- Readable color contrast

\- Descriptive alt text placeholders for images



You are encouraged to keep accessibility in mind when replacing content.
