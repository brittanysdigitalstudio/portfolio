**Playful Portfolio Website Template Readme**



Thank you for purchasing this Playful Portfolio Website Template. This is a simple, friendly HTML and CSS website designed to feel personal, creative, and easy to customize, even if you are new to editing code.



**What This Template Is**



This template is a single page portfolio website. It is great for:



* Designers
* Developers
* Creatives
* Students
* Personal or fun professional portfolios



The layout is intentionally minimal and calm, with playful details like rounded cards, soft colors, and subtle hover effects.



**Files Included**



You will receive the following files:



* index.html The main website file
* styles.css All styling for the website
* (Optional) placeholder image references



No frameworks or build tools are required.



**How To Use**



1. Open index.html and styles.css in a code editor such as VS Code or Notepad++.
2. Replace the text with your own name, bio, and project details.
3. Update links and button text as needed.
4. Add your own images if desired.
5. Open index.html in a browser to preview your site.



**Editing Colors and Fonts**



All colors and fonts are controlled at the top of the CSS file using variables.



Look for this section in styles.css:

:root {

--color-bg: #fdf6ec;

--color-text: #3f3a36;

--color-accent: #4edfd1;

--font-heading: "Space Grotesk", sans-serif;

--font-body: "Inter", sans-serif;

}



You can safely change these values to customize the look of your site without breaking the layout.



**Images**



* The profile image is optional.
* Project card images are optional and can be replaced with real images or left as neutral placeholders.
* Always update the alt text on images to describe the image content.



**Accessibility Notes**



This template was built with accessibility in mind.



* Semantic HTML is used for structure
* Clear color contrast for readability
* Focus styles are included for keyboard users
* Responsive layout that works on mobile and desktop



You are encouraged to keep accessibility in mind when adding your own content.



**Customization Tips**



* You can duplicate or remove project cards as needed
* You can remove dividers if you prefer a cleaner look
* You can adjust spacing values safely in the CSS



All major sections are clearly commented in the code to make editing easier and less intimidating.
