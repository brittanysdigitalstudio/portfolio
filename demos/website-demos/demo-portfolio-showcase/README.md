Portfolio Showcase Template Readme



Thank you for purchasing this portfolio showcase website template.

This template is designed to be calm, accessible, and easy to customize — even if you are new to HTML and CSS.



**What This Template Is For**

This template is best suited for:



* Designers, developers, writers, and creatives
* Personal portfolios
* Simple project showcases
* Resume-adjacent websites



It is not a CMS theme or website builder plugin. It is a static website built with HTML and CSS.



**Files Included**

index.html - The main website file

styles.css - All styling for layout, colors, and typography



No JavaScript is used in this template.



**Beginner \& ADHD-Friendly Design**

This template was intentionally built to:



* Use clear section labels and comments
* Avoid unnecessary complexity
* Be easy to edit without fear of breaking the layout
* Reduce visual clutter



You can safely:



* Change text
* Replace images
* Duplicate or remove project items



**Accessibility Notes**

Accessibility was a priority in this template.



Included features:



* Semantic HTML structure
* Keyboard-accessible navigation
* Visible focus styles for links
* Skip-to-content link for screen reader and keyboard users
* Respects reduced-motion preferences



No ARIA attributes are required for normal editing.



**Replacing Project Images**

Each project uses a standard <img> element.



When replacing images:



* Keep images reasonably sized for the web
* Update the alt text to briefly describe the image



Example:



"Screenshot of a two-column resume website"



**Customizing Colors \& Fonts**



All colors, fonts, and spacing are controlled using CSS variables at the top of styles.css.



You can safely edit:



* Background color
* Text color
* Accent color
* Card background and shadow



Tip: Make small changes and refresh your browser to preview.



**Editing the Project Section**

Each project is an article inside a list.



To add a project:



* Duplicate an existing project block
* Update the title, description, image, and link



To remove a project:



* Delete the entire project block



**How to Publish**

This is a static website. You can publish it using:



* GitHub Pages
* Netlify
* Vercel
* Any basic web hosting provider



Upload both files to the same folder.
