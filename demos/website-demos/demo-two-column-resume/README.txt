TEMPLATE OVERVIEW
This resume template uses a two column layout on larger screens to clearly separate primary content (experience and projects) from supporting information (skills and education).

On smaller screens, the layout automatically stacks into a single column for readability and accessibility.

LAYOUT STRUCTURE

- Header: Name, job title, and social links
- Main Column:
  - About
  - Experience
  - Projects
  - Contact
- Side Column:
  - Skills
  - Education
- Footer: Copyright or additional notes
